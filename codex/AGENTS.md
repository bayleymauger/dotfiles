# Global Agent Instructions

These instructions apply to work performed from this home directory unless a
repository's own `AGENTS.md` provides more-specific guidance.

## Working practices

- Read the repository's instructions and existing conventions before editing.
- Preserve unrelated user changes; do not discard or overwrite them.
- Keep changes focused on the requested task and verify them with the most
  relevant available checks.
- Prefer small, understandable changes over broad refactors.
- Do not commit, push, or alter external services unless explicitly asked.
- For file search or grep in a git-indexed directory, use the `fff` MCP tools
  when available.

## Safety

- Treat credentials, tokens, and personal data as sensitive; never expose
  them in output or commit them to a repository.
- Confirm the exact target before destructive operations.
